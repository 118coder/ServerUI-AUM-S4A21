# ServerS4A12 管理工具包

[AGPL v3.0] [.NET 10.0] [Windows 10/11]

---

## 项目简介

为 ServerS4A12 服务端模拟器打造的全功能管理套件，专为非技术用户设计，无需了解 .NET SDK、PowerShell 或服务端架构，即可轻松完成：

- **同步更新**：一键增量/全量更新，自动拉取最新源码并编译，失败可切换镜像下载
- **存档管理**：切换/改名/导入/导出/备份，支持拖拽换挡，自动备份上限 10 个
- **DX11/DX12渲染**：一键切换补丁，提升游戏流畅度，支持去除 dgVoodoo 水印
- **GM工具**：集成官方同步更新版本，一键启动网页管理后台
- **服务端控制**：启停/重启管理 + PVF 状态检测，自动打开游戏客户端
- **环境检测**：自动检测并安装 .NET SDK，兼容性低系统红字提醒
- **管理器自更新**：从 GitHub 拉取最新源码，自动重新编译并替换 EXE
- **迷你模式**：小窗口快捷入口（开始游戏 / GM工具 / 开始更新 / 存档切换）

## 快速开始

### 系统要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10 (Build 14393/1607+) / Windows 11 x64 |
| .NET运行时 | 有依赖版需 .NET 10；无依赖版免安装（自动检测） |
| 磁盘空间 | 约 2GB |
| 网络 | 首次更新需联网拉取源码 |

### 使用步骤

1. 解压发布包，将 EXE 放到游戏主目录（与 DNF.exe 同级）
2. 双击 `ServerUI-有依赖版.exe` 或 `ServerUI-无依赖版.exe`
3. 左侧菜单「开始」页，点击「开始更新」拉取并编译服务端（约 5~15 分钟）
4. 可选：在「设置与关于」页勾选 DX11/DX12 运行方式
5. 点击绿色大按钮「开始游戏」，程序自动启动服务端（约 5~15 秒）并打开游戏
6. 创建或选择角色，直接开始游玩

> 若 DNF.exe 不在同一目录，程序会以醒目的亮红加粗日志提醒。

### 本地编译

```powershell
# 有依赖版 (~3.65MB)
dotnet publish ServerUI.csproj -c Release -r win-x64 --no-self-contained -o ./publish-deps

# 无依赖版 (~50.6MB, 单文件压缩, 自包含运行时)
dotnet publish ServerUI.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=false -o ./publish-self
```

> 单文件压缩（`EnableCompressionInSingleFile`）由 csproj 按 `SelfContained` 自动启用，体积约 114MB → 50.6MB（降 56%）。注意：WinForms 不支持 Native AOT（NETSDK1175）。

## 常见问题

**Q: 首次使用需要联网吗？**  
A: 需要，用于下载服务端源码；有依赖版还需安装 .NET 10 SDK。

**Q: 便携版和依赖版区别？**  
A: 无依赖版自包含 .NET 运行时（~50.6MB），适合无环境系统；有依赖版（~3.65MB）需系统已安装 .NET 10 SDK。

**Q: 更新失败怎么办？**  
A: 检查网络和防火墙，勾选日志条的「镜像下载」后重试，或改用「全量更新」。

**Q: 游戏黑屏/闪退？**  
A: 在「设置与关于」页切换「可选运行方式」（DX11/DX12），或取消选择相关运行方式。

**Q: 卡在赛丽亚房间？**  
A: 在「设置与关于」页点「修复赛丽亚房间问题」。

**Q: 存档操作被阻止？**  
A: 服务端运行中会阻止存档操作，请先「停止服务端」。
