================================================================
 ServerS4A21 管理器 — 打不开/无法运行 排查指南
================================================================

【支持的系统范围】
  · Windows 10 1607 (2016年) 及以上 全版本 (含专业版/家庭版/企业版)
  · Windows 11 全版本
  · 64 位 (x64) 系统

================================================================
【常见问题与解决】
================================================================

问题 1: 双击"有依赖版"没有任何反应 / 弹英文错误
  原因: 系统未安装 .NET 10 桌面运行时 (Win10 默认不预装)
  解决:
    a) 改用"无依赖版" (自带运行时, 免安装) ← 推荐
    b) 安装 .NET 10 Desktop Runtime (x64):
       https://dotnet.microsoft.com/download/dotnet/10.0
       选择 ".NET Desktop Runtime 10.x (x64)"

问题 2: 双击"无依赖版"无反应 / 被杀毒软件删除 / 报"病毒"
  原因: 无依赖版是单文件自解压程序 (启动时解压运行时到临时目录),
        杀毒软件 (Defender/360/火绒/电脑管家等) 易误报拦截
  解决:
    a) 打开杀毒软件的信任区/白名单, 添加本程序
    b) Windows Defender: 设置 → 病毒和威胁防护 → 排除项 → 添加本程序
    c) 若已被删除, 请恢复后加入白名单再运行

问题 3: 提示"已阻止此应用" / SmartScreen 蓝屏弹窗
  原因: 从网络下载的文件带"网络标记", Win10 SmartScreen 拦截
  解决:
    a) 右键 exe → 属性 → 勾选"解除锁定" → 确定
    b) 或点 SmartScreen 弹窗中的"仍要运行"

问题 4: 双击后有图标但窗口不出现 / 一闪而过
  原因: 多为临时目录被限制 (企业域/精简系统) 或安全软件拦截自解压
  解决:
    a) 检查 EXE 同目录下的 ServerUI-启动日志.txt 与 ServerUI-崩溃日志.txt
    b) 将日志发给开发者协助排查
    c) 尝试以管理员身份运行

问题 5: 提示"系统版本过低"
  原因: 系统低于 Windows 10 1607 (例如 Win10 1507/1511 老镜像)
  解决: 升级系统到 Win10 1607+ 或 Win11

问题 6: 打不开但系统是 32 位
  原因: 本程序仅支持 64 位 (x64) 系统
  解决: 使用 64 位系统, 或更换设备
